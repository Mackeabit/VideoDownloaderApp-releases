# 개인정보와 오류 보고

앱은 별도 계정·분석 서버·원격 측정 기능을 사용하지 않습니다. 요청한 사이트, 미디어 서버 및 사이트가 요구하는 공개 API로 다운로드 요청을 보냅니다. 상대 서버는 일반 웹 요청처럼 IP 주소와 요청 정보를 받을 수 있습니다.

**업데이트 확인**을 누르면 GitHub에 앱의 최신 공개 릴리스를 조회합니다. 인증 토큰, 대기열 또는 영상 URL을 보내지 않습니다. GitHub는 일반 웹 요청처럼 IP 주소와 앱 버전이 포함된 User-Agent를 받을 수 있습니다. 실행 시 자동 확인이나 자동 설치는 하지 않습니다.

URL, 저장 폴더, 대기열 상태와 작업 기록은 이 PC의 `%LOCALAPPDATA%\VideoDownloaderApp`에 저장합니다. 영상·부분 파일은 사용자가 선택한 폴더에 저장합니다. 프로그램 폴더를 지워도 이 데이터는 자동으로 삭제하지 않습니다.

URL에는 접근 토큰이나 개인 식별값이 들어갈 수 있습니다. 오류 표시에서는 비밀값을 가리지만 원본 대기열·요청 파일은 URL을 보관하므로 공개하면 안 됩니다. 쿠키를 가져오거나 로그인 정보를 수집하는 기능은 없습니다.

문제를 보고할 때 앱 버전, Windows 버전, 재현 순서, 공개 가능한 사이트 종류와 가린 오류 메시지를 제공하세요. 대기열 파일 전체, 쿠키, 비공개 URL, 다운로드한 개인 파일을 첨부하지 마세요. 보안 문제에 민감한 정보가 있다면 공개 이슈에 그대로 올리지 마세요.

실패 항목의 **문제 해결** 화면에서 진단 보고서를 미리 보고 복사·저장할 수 있습니다. 원본 URL·제목·개인 경로·계정 정보·전체 로그는 제외합니다. 사이트 이름은 선택한 경우에만 호스트 이름으로 포함하며 기본은 제외입니다. 보고서는 자동 전송하지 않습니다. 링크 재분석은 해당 사이트에 정보 조회 요청을 보내며, 작업 전용 임시 파일은 종료·취소 후 정리합니다. 자세한 절차는 [문제 해결 안내](SUPPORT.md)를 참고하세요.

**대기열에 추가**를 누르면 입력한 URL의 영상 정보를 해당 사이트·미디어 서버·공개 API에 조회합니다. 분석 중인 URL, 영상 제목, 실패 사유, 저장 폴더와 선택한 화질은 이 PC의 `analysis.json`에 저장되어 재실행 후에도 남습니다. **선택 결과 삭제**로 남은 분석 항목을 지울 수 있습니다. 원본 URL이 포함되므로 `analysis.json`도 공개하거나 진단 보고서에 첨부하지 마세요. 사전 분석은 영상 파일을 다운로드하지 않으며 사이트에 대한 정보 조회 요청은 발생합니다.
