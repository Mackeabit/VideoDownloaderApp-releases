# v0.1.9 변경사항

[Windows 64비트 실행 ZIP 다운로드](https://github.com/Mackeabit/VideoDownloaderApp-releases/releases/download/v0.1.9/VideoDownloader-0.1.9-win-x64.zip)

## 수정 사항

- 메인 화면의 공통 화질 옵션을 제거했습니다. **대기열에 추가** 시 URL을 분석하고 영상별 화질을 선택합니다.
- 해상도가 확인된 영상만 화질 선택지를 표시하며, 정보가 없으면 원본으로 받도록 안내합니다.
- 성공한 URL만 먼저 추가할 수 있고, 실패한 URL과 사유는 남겨 **선택 재분석**으로 다시 확인할 수 있습니다.
- 분석 결과와 아직 추가하지 않은 선택값은 앱을 다시 실행해도 유지됩니다. 분석 취소와 저장 실패 시에도 URL을 보존합니다.

사전 분석은 실제 다운로드 성공을 보장하지 않습니다. 기존 대기열·화질 설정과 저장 파일은 유지하며, 자동 해상도 변환은 하지 않습니다.

## 실행과 업데이트

ZIP 전체를 풀고 `VideoDownloader.exe`를 실행하세요. Python·Node·FFmpeg를 별도로 설치할 필요가 없습니다.

기존 버전을 닫고 새 ZIP을 별도 폴더에 풀어 실행하면 대기열과 설정을 계속 사용할 수 있습니다. 영상과 부분 파일은 저장 폴더에 보존됩니다. [사용 안내](USER_GUIDE.md)

## 지원 범위와 파일 확인

Windows x64용입니다. 사이트 변경과 접근 제한에 따라 다운로드가 실패할 수 있으며, 로그인·DRM·실시간 방송·재생목록은 지원하지 않습니다. 실행 파일의 전자서명과 업데이트 자동 설치는 포함하지 않습니다.

파일의 SHA-256은 릴리스의 `SHA256SUMS.txt`에서 확인할 수 있습니다. 외부 구성요소 소스와 체크섬도 같은 릴리스에서 제공합니다.
