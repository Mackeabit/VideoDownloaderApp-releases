# 문제 해결과 진단 보고서

실패하거나 중단된 항목을 선택하고 아래의 **문제 해결**을 누르세요. 오류 종류에 맞는 안내를 확인하고, **링크 다시 분석**으로 현재 영상 정보를 조회할 수 있습니다. 분석은 별도 작업 프로세스에서 실행되며 취소할 수 있습니다. 영상 파일을 저장하거나 기존 대기열을 고치지 않습니다. 정보 조회 성공은 실제 전송·병합 성공을 보장하지 않습니다.

**업데이트 확인**은 사용자가 눌렀을 때 GitHub의 최신 공개 릴리스를 조회합니다. 새 버전이 있으면 배포 페이지를 열어 ZIP을 받을 수 있습니다. 파일을 자동 설치하거나 AI 계정을 요구하지 않습니다. GitHub 연결 실패·요청 제한·공개 릴리스 없음은 따로 안내합니다.

진단 보고서는 앱·엔진 버전, 오류 분류, 처리 단계, 추출 경로, HTTP 응답 코드와 화질 설정을 담습니다. 공유 전 미리보기를 확인하고 **복사** 또는 **보고서 저장**을 선택하세요. 자동으로 전송하지 않습니다. 원본 URL, 영상 제목, 개인 경로, 계정 정보, 전체 로그는 제외합니다. **사이트 이름 포함**은 기본으로 꺼져 있으며 켜면 호스트 이름만 담습니다. 재현에 필요한 공개 영상 주소는 사용자가 별도로 제공할 수 있습니다. 대기열 전체나 로그인 쿠키를 첨부할 필요는 없습니다.
