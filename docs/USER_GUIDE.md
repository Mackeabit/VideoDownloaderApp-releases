# 영상 다운로드 0.1.7 사용 안내

## 실행과 다운로드

1. [v0.1.7 실행 ZIP](https://github.com/Mackeabit/VideoDownloaderApp-releases/releases/download/v0.1.7/VideoDownloader-0.1.7-win-x64.zip)을 받아 전체 압축을 풉니다.
2. `VideoDownloader.exe`를 실행합니다. 옆의 `_internal` 폴더도 필요합니다.
3. 영상 URL을 한 줄에 하나씩 입력합니다.
4. 저장 폴더와 화질 상한을 선택하고 **대기열에 추가**를 누릅니다.
5. **다운로드 시작**을 누르면 대기열 순서대로 저장합니다.

Python·Node·FFmpeg와 글꼴은 앱에 포함되어 있어 별도로 설치할 필요가 없습니다.

## 대기열 관리

- **선택 취소**: 선택한 작업을 취소합니다.
- **선택 재시도 / 이어받기**: 실패하거나 중단된 작업을 다시 시도합니다. 이어받기는 서버가 지원하는 경우에 가능합니다.
- **현재 항목 후 멈춤**: 현재 다운로드를 마친 뒤 대기열을 멈춥니다.
- **완료 항목 정리**: 완료 기록을 목록에서 지웁니다.
- **선택 항목 삭제**: 선택한 기록을 목록에서 지웁니다. 현재 진행 중인 작업은 제외합니다.
- **상세 정보**: 실제 해상도·길이·파일 형식과 저장 경로를 확인합니다.

기록을 정리하거나 삭제해도 영상 파일과 부분 파일은 보존됩니다. 삭제한 작업을 다시 받으려면 같은 URL·저장 폴더·화질로 추가하세요. Ctrl 또는 Shift로 여러 항목을 선택할 수 있습니다.

대기열은 재실행 후에도 복원됩니다. 앱을 닫으면 진행 중인 작업을 취소한 뒤 종료하며, 이후 중단 항목을 선택해 재시도할 수 있습니다.

## 저장 위치와 화질

기본 저장 폴더는 Windows 다운로드 폴더 아래 `VideoDownloader`입니다. 저장 폴더와 화질을 변경하면 이후 새로 추가하는 작업에 적용됩니다.

화질은 **세로 해상도 상한**입니다. 예를 들어 1080×1920 세로 영상은 1080p 이하 설정에서 제외됩니다. 해상도 정보가 없는 형식은 다운로드한 파일의 실제 해상도로 상한을 검사합니다. 상한을 넘으면 실패로 표시하고 파일은 보존하며, 자동으로 코덱이나 해상도를 변환하지 않습니다.

0.1.7에는 해상도 정보가 없는 HTML5/MP4가 화질 필터에서 제외되던 문제의 수정이 포함됩니다. 이 수정이 없는 기존 배포본에서는 **최고 화질**을 선택해 링크를 새로 추가하면 해당 필터를 피할 수 있습니다.

MP4는 우선 선택하는 형식이며, 코덱을 변환하지는 않습니다. 실제 확장자는 원본에 따라 달라질 수 있습니다. 무음 영상은 완료 검사에서 실패로 표시될 수 있으며 파일은 보존됩니다.

**링크 추가**와 **상세 정보** 영역을 접으면 목록을 더 넓게 볼 수 있습니다.

## 실패했을 때

실패·취소·중단 항목을 선택하고 **문제 해결**을 누르세요. 원인 안내, 링크 재분석, 진단 보고서 미리보기·복사·저장을 사용할 수 있습니다. [문제 해결 안내](SUPPORT.md)

저장 실패 메시지가 나오면 저장 위치의 권한·남은 공간·파일 잠금을 확인한 뒤 다시 시도하세요. 대기열 저장에 실패한 새 작업은 시작되지 않습니다. 재시도나 대기 항목 취소 상태를 저장하지 못했을 때도 안내 메시지를 확인하세요.

공개된 단일 영상 중심이며 로그인·쿠키 가져오기·DRM·실시간 방송·재생목록은 지원하지 않습니다. 사이트 변경과 접근 제한에 따라 실패할 수 있습니다. 모든 사이트에서 다운로드할 수 있는 것은 아닙니다.

## 업데이트와 데이터 보존

**업데이트 확인**을 누르면 최신 공개 버전을 조회합니다. 새 버전이 있으면 배포 페이지에서 ZIP을 받으세요. 앱을 닫고 새 ZIP을 별도 폴더에 풀어 실행하면 기존 대기열과 설정을 이어서 사용합니다. 자동 설치는 하지 않습니다.

대기열·설정·작업 기록은 `%LOCALAPPDATA%\VideoDownloaderApp`에, 영상과 부분 파일은 선택한 저장 폴더에 저장합니다. 프로그램 폴더를 지워도 이 데이터는 자동으로 삭제되지 않습니다.

진단 보고서는 자동 전송하지 않습니다. 원본 URL·제목·개인 경로·계정 정보·전체 로그를 제외하며, 사이트 이름 포함 여부는 직접 선택합니다. 대기열 파일 전체나 비공개 URL을 공개 이슈에 올리지 마세요. [개인정보 안내](PRIVACY.md)
