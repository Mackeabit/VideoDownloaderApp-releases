# 영상 다운로드 0.1.5

ZIP 전체를 원하는 폴더에 풀고 VideoDownloader.exe를 실행하세요.
EXE 옆의 _internal 폴더도 필요합니다. Python, Node, FFmpeg를 별도로 설치하지 않아도 됩니다.
화면 글꼴은 앱에 포함된 Pretendard입니다. 글꼴을 따로 설치할 필요가 없습니다.

1. 영상 URL을 한 줄에 하나씩 입력합니다.
2. 저장 폴더와 화질 상한을 선택한 뒤 [대기열에 추가]를 누릅니다.
3. [다운로드 시작]을 누르면 한 개씩 순서대로 받습니다.
4. 항목을 선택해 [선택 취소] 또는 [선택 재시도 / 이어받기]를 사용할 수 있습니다.
5. [현재 항목 후 멈춤]은 현재 작업을 마친 뒤 대기열을 멈춥니다.
6. 완료 항목을 선택하고 [상세 정보]를 펼치면 실제 해상도·길이·파일 형식과 저장 경로를 확인할 수 있습니다.
7. 목록 아래의 [완료 항목 정리]는 완료된 항목을 모두 목록에서 지웁니다. 영상 파일과 부분 파일은 그대로 보존하며, 대기·진행·실패·취소·중단 항목은 남습니다. 정리 결과는 재실행 후에도 유지됩니다. 완료 항목이 없으면 버튼은 비활성화됩니다.
8. [선택 항목 삭제]는 선택한 실패·취소·중단·완료·대기 항목을 목록에서만 지웁니다. Ctrl 또는 Shift로 여러 항목을 선택할 수 있습니다. 영상 파일과 부분 파일은 보존하며, 현재 작업 중인 항목은 함께 선택해도 남습니다. 선택이 없거나 현재 작업 중인 항목만 선택하면 버튼은 비활성화됩니다. 삭제 결과는 재실행 후에도 유지됩니다.

삭제한 취소·중단 항목을 다시 받으려면 같은 URL·저장 폴더·화질로 추가하세요. 남아 있는 부분 파일은 사이트가 지원할 때 이어받습니다.

대기열은 저장에 성공한 뒤에만 추가됩니다. 저장 실패 안내가 나오면 입력한 URL과 기존 목록이 그대로 남고 새 작업은 시작되지 않습니다. 저장 위치의 권한이나 파일 잠금 문제를 해결한 뒤 다시 추가하세요. 기본 설정만 저장하지 못한 경우에는 대기열 추가 성공과 설정 저장 실패를 구분해 안내합니다.

[링크 추가]를 누르면 URL 입력과 저장 옵션을 접거나 펼칠 수 있습니다. 작은 창에서는 여백과 입력 영역이 줄어들며, [상세 정보]를 펼치면 입력 영역이 접혀 목록 공간을 확보합니다. 창 너비가 작으면 속도 열을 숨기며, 진행 중인 항목의 속도는 상세 정보에서도 확인할 수 있습니다. 접거나 창 크기를 바꿔도 입력 내용과 선택한 항목은 유지됩니다.

앱을 닫으면 실행 중인 작업을 취소한 뒤 종료합니다. 응답이 없는 작업은 약 5초 후 해당 작업의 프로세스를 정리합니다. 완료 파일과 .part/이어받기 정보는 보존합니다. 재실행 후 중단 항목을 선택해 재시도하세요. 이어받기는 서버와 프로토콜이 지원하는 경우에 가능합니다.

화질은 세로 해상도 상한입니다. 세로형 영상의 1080×1920은 1080p 이하 설정에서 제외됩니다. 사이트가 해상도를 알려주지 않으면 상한을 지키기 위해 실패할 수 있습니다. 이 경우 최고 화질을 선택해 다시 추가할 수 있습니다. MP4는 우선 형식이며 코덱 변환은 하지 않습니다. 실제 확장자·코덱은 원본에 따라 달라집니다.

대기열에 넣은 뒤 저장 폴더·화질을 변경하면 새로 추가하는 항목에 적용됩니다. 동일한 폴더·화질·영상은 중복 추가하지 않습니다. 실패·취소 항목은 선택 후 재시도하세요.

특정 사이트만 허용하는 방식은 아닙니다. HTTP(S) URL을 받아 yt-dlp의 기본 추출기를 사용하고, 영상 주소 추출이 지원되지 않을 때 일반 추출기로 다시 시도합니다. 그래도 실패하면 해당 URL과 일치하는 검토된 개별 어댑터가 있을 때만 대체 경로를 사용합니다. 일반 추출기는 직접 미디어 주소나 인식 가능한 웹페이지 영상을 처리하지만 모든 사이트의 플레이어를 해석하지는 못합니다. 사이트 지원 범위는 내장 엔진과 영상 접근 조건에 따라 달라집니다.

로그인, 쿠키 가져오기, DRM, 실시간 방송, 재생목록 확장은 첫 버전에 포함하지 않습니다. 사이트 변경이나 접근 제한에 따라 실패할 수 있습니다. 완료 판정은 파일 존재·영상·음성·재생 시간과 선택한 화질 상한 검사에 근거합니다. 무음 영상은 음성 검사를 통과하지 못하며 파일은 보존됩니다.

기본 저장 폴더: Windows 다운로드 폴더 아래 VideoDownloader.
앱 설정·대기열·작업 기록: %LOCALAPPDATA%\VideoDownloaderApp.
URL과 저장 경로는 이 PC의 대기열 기록에 저장됩니다. 진단 오류 메시지의 URL 비밀값과 쿠키는 가립니다. 로그인 정보를 수집하거나 서버에 대기열을 전송하지 않습니다.

실패·취소·중단 항목을 선택하고 [문제 해결]을 누르면 오류별 안내, 링크 재분석, 진단 보고서 미리보기·복사·저장을 사용할 수 있습니다. 보고서는 자동 전송하지 않으며 원본 URL·제목·개인 경로·계정 정보·전체 로그를 제외합니다. 사이트 이름 포함은 기본으로 꺼져 있습니다. 링크 재분석은 별도 작업에서 영상 정보를 조회하며 실제 파일을 저장하지 않습니다.

[업데이트 확인]은 GitHub의 최신 공개 릴리스를 조회합니다. 새 버전이 있으면 배포 페이지에서 ZIP을 받아 업데이트하세요. 확인 실패는 기존 다운로드에 영향을 주지 않습니다. AI 계정이나 API 키가 필요하지 않습니다.

Windows x64용 포터블 앱입니다. 전자서명과 자동 설치는 포함하지 않습니다. [앱 정보 · 라이선스]에서 버전과 앱 이용 조건을 확인하고 고지 폴더를 열 수 있습니다. 자체 원본 소스는 비공개이며, 외부 구성요소의 고지와 라이선스 원문은 THIRD_PARTY_NOTICES.md 및 _internal/notices에 있습니다. 필요한 외부 구성요소 대응 소스는 같은 릴리스에서 제공합니다. 기존 GPL 버전의 권리는 유지됩니다.

재시도와 대기 항목 취소도 저장 성공 여부를 확인합니다. 저장에 실패하면 재시도를 시작하지 않으며, 취소 기록을 저장하지 못하면 이후 대기열 실행을 멈춥니다. 진행 중인 작업의 취소는 계속 처리합니다. 저장 실패 원인을 해결한 뒤 목록 상태를 확인하고 다시 실행하세요.
